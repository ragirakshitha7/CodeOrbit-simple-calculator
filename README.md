# Simple Calculator

A beginner-friendly Python calculator that performs basic arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero

## Requirements

- Python 3.x

## How to Run

1. Download or clone this project.
2. Open a terminal in the project folder.
3. Run:

```bash
python calculator.py
```

## Usage

Choose an operation, enter two numbers, and the calculator will display the result.

Example:

```text
Select operation:
1. Add
2. Subtract
3. Multiply
4. Divide

Enter choice: 1
Enter first number: 10
Enter second number: 5

Result: 15
```
